## If you're installing it now

Three steps, and the third is the only one that needs the code.

1. **Get the app** from the App Store using the button above.
2. **Open it and sign in** with Apple. It takes a moment and asks for nothing else.
3. **Enter the code** — during setup, choose *Join with a code*. If you've already finished setting up, it's in **Profile → Have a code?**

Come back to this page any time if you need the code again. That's what it's here for — a code in a message scrolls away, and this doesn't.
